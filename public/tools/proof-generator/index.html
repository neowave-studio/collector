Verify your odds & claim your card

This page runs entirely in your browser. It makes no network requests, loads nothing from a CDN, and needs no server — including ours. Save this folder and it keeps working even if Collector disappears.

1. Is this copy intact?

Confirms the maths in this page produces the same hashes as the deployed contracts. If it fails, the file has been tampered with — get a fresh copy before trusting anything below. 


  


  

    
2. Do the published odds match the chain?

    

      Paste the pool file (fetch it from any IPFS gateway using the poolCID stored on-chain),
      and the root returned by getPoolVersion(packId, version). This checks that
      the odds tile the whole range exactly once — no gaps, no overlaps, no card listed twice — and that
      this file is the one that was actually committed.
    

    
    
    
    
    
    

    

  


  

    
3. Claim your card without us

    

      Read getDraw(drawId) on-chain and copy its winningWeight. This works out
      which card that weight must pay out, builds the Merkle proof, and prints a transaction you can paste
      into any wallet. Anyone can send it — the card always goes to the draw's owner, never
      to whoever submits it.
    

    

      

        
        
      

      

        
        
      

    

    

      

        
        
      

      

        
        
      

    

    

      Use claimAfterTimeout once the buyback window has passed: it is permissionless and can
      never be paused. Use claimUnavailable instead if the card has already gone to an earlier
      draw — you are then paid its committed reference value from the reserve.
    

    
    

    

  


  

    
Randomness never arrived?

    

      If getDraw(drawId).revealed is still false after the reveal timeout, the rip is
      refundable and the escrowed payment goes back to the buyer. This path is never pausable either.
